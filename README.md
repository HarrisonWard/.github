# .github

Default community health files for repositories under [@HarrisonWard](https://github.com/HarrisonWard).

Any repository without its own copy of these files inherits them from here.

| File | Applies to |
|---|---|
| `SECURITY.md` | Every repo. Shows in the Security tab. |
| `CONTRIBUTING.md` | Every repo without its own. |
| `PRINCIPLES.md` | The eleven things I say a lot. Everything published here comes out of them. |

This repository must stay **public** for inheritance to work.
